## Featured projects

### [Sentora](https://github.com/d3vhex/Sentora)
**Self-hosted, AI-assisted SIEM / EDR / SOAR platform**

Sentora brings endpoint telemetry, security detections, investigation, and response workflows into a self-hosted stack. It combines Sigma-based detections, OpenSearch-backed log exploration, local-LLM triage with Ollama, package vulnerability scanning, and SOAR playbooks.

`Python` `React` `TypeScript` `OpenSearch` `RabbitMQ` `Ollama` `Docker`

### [Argos](https://github.com/d3vhex/Argos)
**Framework for authorized red-team operations and security research**

A security research project focused on encrypted agent communication, staged payload delivery, and modular post-exploitation workflows. Intended for controlled labs and explicitly authorized assessments.
